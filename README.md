# Goga Meskhi — bilingual artist website / v4

A static, responsive website based on the approved black / ivory / signal-red editorial mockup. There are 48 HTML pages: the root entry, 23 English pages, 23 Georgian pages and a `404.html` error page. No framework, npm, backend, or build step is needed to view it. The optional Python generator is included to keep the two language versions in sync.

## Run locally
1. Extract the ZIP to a folder.
2. Open `index.html` in a browser; the local navigation and language switch work directly.
3. Locally opened files and the standalone preview now open the original video directly on YouTube. To test the embedded player, serve the folder via HTTP (e.g. `python -m http.server 8000`) or publish to HTTPS hosting. YouTube embeds require an internet connection and may be restricted by YouTube; each player includes a direct link.

## Publish on GitHub Pages
The site is deployed from the `main` branch, `/ (root)`, of the GitHub repository (Settings > Pages > Deploy from a branch). `.nojekyll` and `CNAME` (`gogameskhi.com`) must stay in the root. Pushing to `main` publishes the site.

## SEO
The pages are indexable and are generated for the production domain `https://gogameskhi.com`: localized titles and descriptions, canonical and hreflang links, Open Graph and X card tags, JSON-LD structured data, `robots.txt` and `sitemap.xml`. All of it is produced by `build.py`; the domain, the artist's verified profiles and the per-page titles and descriptions are set in the SEO block near the top of that file. Earlier versions of this prototype carried `noindex, nofollow` while content and photo rights were awaiting approval; that tag has been removed, and the points that still need the artist's decision are listed in `SEO-REPORT.md`.

After any change, run `python build.py`, then `python seo_check.py` (add `--external` to also request every external link) and `python seo_keyword_audit.py` for bilingual keyword coverage. Both checks must end with `0 errors` before publishing. Keyword ownership and page mappings are documented in `SEO-KEYWORDS.md`.

## Files
- `index.html`: English homepage, served at `https://gogameskhi.com/`.
- `en/`, `ka/`: dedicated equivalent localized pages with language switch. `ka/index.html` is the Georgian homepage; `en/index.html` is a copy of the root homepage whose canonical link points to the root.
- `404.html`: bilingual error page that GitHub Pages serves for missing URLs.
- `robots.txt`, `sitemap.xml`: generated by `build.py`.
- `favicon.ico`, `assets/apple-touch-icon.png`, `assets/goga-meskhi-share-card.png`: icons and the default 1200×630 image for link previews. The share card is typographic and contains no photograph.
- `seo_check.py`: audit of the generated pages (metadata, canonical and hreflang links, structured data, headings, images, links, sitemap). Uses only the Python standard library.
- `seo_keyword_audit.py`: bilingual keyword coverage per canonical page (titles, descriptions, h1, main); writes `SEO-KEYWORDS.md`.
- `SEO-REPORT.md`: SEO audit findings, changes, test results, open issues and deployment steps.
- `SEO-KEYWORDS.md`: primary/secondary keyword map, priority phrase coverage, track/story targets (regenerated by the keyword audit).
- `assets/style.css`: all responsive design, typography, colors.
- `assets/main.js`: menus, click-to-load video dialog, music-category filters, inquiry drafting.
- `assets/photo-sources.json`: remote published photo and video thumbnail URLs. `image-fallback.svg` is a neutral typographic fallback. No generated photographs are included.
- `build.py`: centralized bilingual content and page generator (`python build.py`). Uses only the Python standard library.
- `CONTENT-REVIEW.md`: sources, design assumptions and publication checklist.

## V4 — YouTube Error 153 fix
Local files, standalone previews and framed previews open the original YouTube watch URL in a new tab instead of attempting playback in a context that may lack a Referer. Published pages use the IFrame Player API with `strict-origin-when-cross-origin`, the actual page origin, and a visible direct-watch link. Player errors and API/loading timeouts show a bilingual link to the original video. The website does not bypass video-owner embedding restrictions. See https://developers.google.com/youtube/iframe_api_reference and https://developers.google.com/youtube/terms/required-minimum-functionality. Live playback remains dependent on YouTube, browser policies and hosting configuration; verify on the real published domain.
